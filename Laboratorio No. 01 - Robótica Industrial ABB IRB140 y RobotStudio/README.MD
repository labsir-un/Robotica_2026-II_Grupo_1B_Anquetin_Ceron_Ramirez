# Laboratorio 1: Robotica Industrial – Trayectorias, Entradas y Salidas Digitales
## Alejandro Ramirez - Ronan Anquetin - Nirvana Ceron
### Introduccion
El principal objetivo de este laboratorio era entender los principiode como funciona robots a nivel industrial, tanto a nivel de sus diversas formas de funcionamiento como en la operacion práctica, y finalmente como la combinacion de herramientas propias junto al uso del simulador de RobotStudio pueden unirse para que el robot pueda desarrollar tareas de gran complejidad.
### Desarrollo
El primer paso para la realización de este laboratorio fue aprender a usar las herramientas para llevar la práctica a buen término, en este aspecto RobotStudio fue de lejos la más desafiante en virtud de que desde ahi es donde saldrán las tareas de mayor complejidad en lo que la práctica respecta
El trabajo con la herramienta y el pastel fue más sencillo, al menos inicialmente. La herramienta fue creada en AutoCAD
